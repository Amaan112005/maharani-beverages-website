## Operating rules (short form)

No production deploy without G4 approval · no fabricated facts (registers gate everything) · every change needs a register row with evidence + rollback · GA4 stays off until OC-20 · release gate = strict parse + crawl + CDP suite · evidence classes [F/O/R/H/U] everywhere.

## Cadence

Monthly: management report (16-monthly-reviews/) + GSC export + battery + Lighthouse. Continuous: experiment windows per register. Quarterly: entity audit, content refresh sweep, risk-register review.
