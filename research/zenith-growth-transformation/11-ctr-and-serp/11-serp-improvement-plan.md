# 11 — SERP Improvement Plan

1. **Measurement first** — monthly GSC exports; per-change windows logged in the experiment register (no concurrent overlapping metadata experiments).
2. **Snippet relevance pass** — for each high-impression query: does title+description answer it in the first 120 chars? Rewrite queue built from the keyword DB's zero-click flag (55 queries → grouped by intent → mapped URLs).
3. **Rich-result hygiene** — keep FAQ/product/breadcrumb eligible (1:1 visible rule); merchant feed review with GMC (Month-2 candidate, owner account).
4. **Local surface** — GBP + reviews + citations change the near-me SERP itself; organic snippet work continues in parallel.
5. **Brand SERP** — post-GBP: knowledge panel hygiene, sitelinks influence via clean structure; monitor branded query CTR (currently 8.8% on 195 impr — strong).
6. **Guardrails** — no clickbait; no title churn on winning pages; every change reversible within one commit; measurement gaps disclosed (no live GSC API — export cadence owner-side).
